# Grundstigen i webbläsaren (M5.7)

Chromium (swiftshader), 480×900, `build/web/` serverat på 127.0.0.1:8767,
start på `index.html` **utan query** – samma väg som Anders tog.

Hela tutorialen spelad rum för rum, sedan trappan upp och torget.

| Bild | Vad den visar |
|---|---|
| `01_title` – `03_room01` | Kroppsval → titel → källaren → rum 0.1 |
| `07_room03`, `08_room03_reward` | Rum 0.3, paret, och det berättande `+1 slot`-kortet |
| **`09_room03_loot`** | **Det nya loot-valet: "Loot. Pick one." och tre riktiga sidor** |
| `10_after_loot` | Tillbaka i korridoren med kortet taget |
| `11_room04` – `19_room05_reward` | Rum 0.4 och 0.5. Den valda sidan syns på tärning 2 ("burn 3") |
| `21_room06_charge_through_mirror` | Rum 0.6 löst som det är tänkt: banken hamnar i slot 2, Spegeln kopierar 17 och paret gör 44 |
| `23_room07`, `25_boss_pair` | Bossen och ×2-paret på 26 |
| `28_after_boss_room7` | Efter bossen: `FORWARD · stairs up` |
| **`29_town_chalkrim`** | **Torget Chalkrim – svaret på "det finns ingen stad"** |
| `30_after_reload` | Omladdning: profilen ligger kvar i IndexedDB, titeln erbjuder CHALKRIM |
