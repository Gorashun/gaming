# addictive_gameapp

Enkelt mobilspel (7+) byggt kring täta, oförutsägbara belöningar. Android först, iOS sedan, en kodbas.

- `team/TEAM.md` – agentteamet och arbetsflödet
- `docs/research/` – researchunderlag
- `docs/PROPOSAL.md` – beslutat spelförslag
- `app/` – spelkoden (skapas när förslaget är godkänt)

## Spelregler för projektet
- Kärnloop spelbar i webbläsare innan något paketeras för mobil.
- All balansering i data, aldrig hårdkodad.
- Inga konton, ingen tracking, ingen monetisering i v1. Inga mörka mönster riktade mot barn.
